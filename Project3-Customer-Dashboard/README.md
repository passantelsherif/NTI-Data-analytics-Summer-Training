# 👥 Customer Dashboard – Data Warehousing & BI  

## 📌 Project Overview  
This project focuses on building a **Customer Analytics Dashboard** by applying **data warehousing concepts** (dimensional modeling) and **business intelligence techniques**.  
The workflow includes splitting raw transactional data into **dimension and fact tables**, performing **data modeling**, and building a dashboard with **KPIs and visual insights**.  

---

## 🗂️ Data Preparation & Modeling  

1. **Split the Data into:**
   - **Customer_dim** → Customer attributes (ID, Name, Segment, Region, etc.)  
   - **Product_dim** → Product attributes (ID, Category, Subcategory, etc.)  
   - **Fact Table** → Transactional data (Sales, Profit, Discount, Quantity, Date IDs, etc.)  

2. **Data Modeling:**  
   - Load dimension & fact tables into **Power Pivot**.  
   - Establish relationships between **Fact Table ↔ Dimensions**.  
   - Ensure a **star schema** for optimized reporting.  

---

## 📊 KPIs (Key Performance Indicators)  

1. **إجمالي المبيعات** (Total Sales)  
2. **إجمالي الربح** (Total Profit)  
3. **إجمالي الخصومات** (Total Discounts)  
4. **عدد الطلبات** (Number of Orders)  
5. **عدد العملاء** (Number of Customers)
