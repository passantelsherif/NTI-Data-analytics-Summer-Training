# Project 1: E-commerce Database

### Overview
This project demonstrates database design for an **E-commerce system**, including ERD, mapping, normalization, SQL implementation, and data insertion.

---

## Contents
1. **ERD** – Entity Relationship Diagram for the system.
2. **Mapping** – Mapping between ERD and relational schema.
3. **Normalization** – Steps confirming 1NF → 3NF.
4. **SQL Implementation** – DDL (table creation).
5. **Data Insertion** – Inserted 5 sample rows per table.

---

## Tools
- SQL Server
- Draw.io (for ERD)

---

## How to Run
1. Open the `ecommerce-schema.sql` file.
2. Run the script in your SQL environment.
3. Insert sample data using `insert-rows.sql`.
4. Query the database for insights.
