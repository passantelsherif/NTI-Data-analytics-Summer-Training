# Project 2: Supermarket Dashboard

### Overview
An interactive **Supermarket Sales Dashboard** built using Excel to analyze sales trends, KPIs, and performance insights.

---

## Features
- Data cleaning with Excel Power Query.
- KPI tracking (Total Sales, Top Products, Profit Margin).
- Power BI dashboard with filters & visuals.

---

## Tools
- Excel 

---

## Example Insights
- Which products contribute most to revenue?
- Sales trends over months.
- Customer purchase behavior.
